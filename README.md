# 🧮 CalcMath

Uma calculadora acessível desenvolvida em Python utilizando Tkinter.
O projeto possui interface moderna, suporte a áudio e foco em acessibilidade e usabilidade.

# 🚀 Tecnologias Utilizadas

* Python 3
* Tkinter
* pyttsx3

---

# 📦 Instalação

Clone o repositório:

```bash
git clone https://github.com/iLGuilhermeDev/calcmath.git
```

Entre na pasta:

```bash
cd calcmath
```

Instale as dependências:

```bash
pip install pyttsx3
```

Execute o projeto:

```bash
python calculo.py
```

---

# 🎮 Controles

| Tecla     | Função          |
| --------- | --------------- |
| 0-9       | Inserir números |
| + - * /   | Operações       |
| Enter     | Calcular        |
| C         | Limpar          |
| Backspace | Apagar          |
