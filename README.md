# 🧮 CalcMath

Uma calculadora acessível desenvolvida em Python utilizando Tkinter.
O projeto possui interface moderna, suporte a áudio e foco em acessibilidade e usabilidade.

# 📦 Instalação

Clone o repositório:

```bash id="4tln5q"
git clone https://github.com/iLGuilhermeDev/calcmath.git
```

Entre na pasta:

```bash id="z7m2ba"
cd calcmath
```

Instale as dependências:

```bash id="m1wy1j"
pip install pyttsx3
```

Execute o projeto:

```bash id="1omc2m"
python calculo.py
```

---

# 🎮 Controles

| Tecla     | Função          |
| --------- | --------------- |
| 0-9       | Inserir números |
| + - * /   | Operações       |
| Enter     | Calcular        |
| C         | Limpar          |
| Backspace | Apagar          |
